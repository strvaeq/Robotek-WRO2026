This part works as the mount for the LiDAR sensor. In this updated design, the sensor is positioned lower to significantly improve obstacle detection. The design includes screw holes that secure it firmly to both the vehicle chassis and the LiDAR itself, ensuring stability while the robot moves.

**Model Details**
- Format: `.stl`
- Material: PLA
- Layer height: 0.24 mm
- Infill: 25%
- Supports: Yes, for internal cavities
